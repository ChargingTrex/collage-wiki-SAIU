# Sai University Club & Event Wiki

This is the documentation home for Sai University's student clubs, fests,
and shared resources. It's organized into three sections:

- **[Clubs](/clubs)** — all 18 student-led clubs: constitutions, exec
  boards, and each club's event history.
- **[Fests](/fests)** — the three annual, university-wide fests
  (Innovision, the Annual College Fest, and MoSAIc).
- **[Resources](/docs/category/resources)** — shared material that isn't tied
  to any single club or fest, starting with the
  [Event Archives](/docs/resources/archives).

Looking for something else?

- **[Explore](/explore)** — every club and fest hero in one place.
- **[Events](/events)** — the full, tag-filterable event feed.
- **[Blog](/student-voices)** — writing published by individual students.

Club leads and members edit these pages directly — see `CONTRIBUTING.md` in
the repository for how to add or update content.
